# Προσκλητήριο γάμου · Christina & Panagiotis

Στατικό site (HTML/CSS/JS, χωρίς build). Όλα τα στοιχεία (ονόματα, ημερομηνία, ώρα, ναός, δεξίωση, RSVP,
γλώσσα, φωτογραφία, μουσική) αλλάζουν στο `CONFIG` στην αρχή του `app.js`.

Ο φάκελος, η σφραγίδα, η κάρτα και ο καθρέφτης είναι σχεδιασμένα σε SVG (ξεχωριστά επίπεδα: πίσω μέρος,
μπροστινή τσέπη, τριγωνικό καπάκι, σφραγίδα, κάρτα), ώστε το καπάκι να ανοίγει σε 3D και η κάρτα να βγαίνει
πίσω από την τσέπη. Η φωτογραφία του ζευγαριού μπαίνει στο `img/` και δηλώνεται στο `CONFIG.photo`.

## Δημοσίευση στο Render
1. GitHub repository με αυτόν τον φάκελο.
2. Render → **New → Static Site** → το repo.
3. **Build Command:** (κενό) · **Publish Directory:** `.`
